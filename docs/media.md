# README media

[Back to README](../README.md)

The opening hero combines desktop and phone captures. Feature images follow the reader's workflow: terminals, mobile, connection-local Files, dual-pane File Transfer, connection profiles, reusable commands and themes.

UI screenshots use the production templates, styles, JavaScript and xterm renderer with demonstration accounts and fixture responses. Hostnames, paths, listings and output are sample data. These images are illustrations of the interface, not evidence of a successful live SSH connection or file operation.

The GIFs are paced sequences of captured UI states. They are not continuous recordings; the file-save state is simulated. Static images remain available alongside the animations for readers who prefer them.

The two file surfaces are deliberately shown separately: `session-files-desktop.png` / `session-files-mobile.png` depict the active connection's Files panel; `filemanager.png` depicts global File Transfer.
